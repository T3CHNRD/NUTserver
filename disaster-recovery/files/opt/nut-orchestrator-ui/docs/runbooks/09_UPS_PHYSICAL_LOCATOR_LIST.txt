IMPORTANT SAFETY RULE

Do not run any command named:

  test.*
  load.*
  shutdown.*
  outlet.*
  bypass.*
  calibrate.*
  driver.killpower

for physical identification.

Only use beeper.enable and beeper.disable on UPS units that expose both commands.
